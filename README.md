## 定制改动点

- **播放器增强**：双指双击开关弹幕（不触发播放/暂停，设置内可单独关闭）、滑动调速（音量/亮度/进度）。
- **动态页精简模式**：开启后去掉顶栏与UP主侧栏，只显示投稿视频，卡片缩小到一行一个（封面在左）或一行两个，点开直接播放；顶部保留搜索栏，并带发布动态、设置入口；另可全局屏蔽带「充电专属」标记的投稿。
- **点踩一步到位**：视频点踩直接生效，配合全场景屏蔽。
- **全场景屏蔽**：屏蔽规则覆盖更多入口。
- **音乐视频自动一倍速**：可自选分区（默认音乐区，鬼畜等任意分区可选），命中的视频自动以 1 倍速起播；同时修复起播后播放器倍速显示与实际不一致的问题。
- **分P连播**：新增播放模式「分P连播」，在同一稿件内按页序连续播放分P（BV 号始终不变），播完最后一个 P 即停止，不进入列表或合集的下一个视频。
- **弹幕不透明度每档 10%**：调节档位从 1% 改为 10%。
- **视频设置项自定义隐藏**：可勾选隐藏右上角不常用的设置项。
- **设置页重启应用按钮**：一键重启，零第三方依赖的 JNI 方案。
- **登录页精简**：仅保留短信登录入口。
- **允许备份**：开启 `allowBackup` 并约定 `backup_rules`。
